Questions people ask

Something missing? Ask us on the free call.

What technology do you use for web apps?

We usually build with React on the front end and Node.js on the back end, with a database chosen to fit your data. If you already have a stack, we can work with it.

Do we own the code?

Yes. The code, design files and data are yours. If you ever move on, we hand everything over.

Will the app work on phones?

Yes. Every app we build is responsive, so it works on phones, tablets and laptops. Currenz, for example, was designed to be used on a phone first.

How do you price a custom web app?

We scope the app on a free call, then send a written quote that lists the features, screens and timeline. Larger apps can be built in stages, so you start using the first version sooner.

Can you maintain and extend the app later?

Yes. We offer ongoing maintenance for updates, fixes and new features as your business grows.
